# 2027 大阪潮玩畢旅｜行程網站

《遊程設計》期末報告用的行程商品頁。原本是 Google 協作平台裡嵌一整段 AI 產生的程式碼，現在改成一般的網站專案：資料、外觀、程式分開放，之後誰要改哪一塊都比較好找。

## 檔案

| 檔案 | 放什麼 | 誰會改 |
| --- | --- | --- |
| `index.html` | 六個頁面的骨架（有哪些區塊） | 很少需要改 |
| `css/style.css` | 外觀：顏色、字體、版面。主色在檔案最上面的 `--main` 系列 | 品牌組員 |
| `js/data.js` | **原網站的行程資料，原封不動搬過來**：每日行程、店家、預算、計程車 | 行程組員 |
| `js/tour.js` | 新版才需要的設定：旅行社名稱、logo、照片、售價、首頁文案、頁面名稱 | 品牌、網頁組員 |
| `js/app.js` | 把資料變成畫面、切換頁面的程式 | 很少需要改 |
| `images/` | 照片和 logo 放這裡 | 大家 |

## 頁面

同一個 `index.html`，網址後面的 `#/…` 決定顯示哪一頁，可以直接分享某一頁的網址：

| 網址 | 頁面 | 內容 |
| --- | --- | --- |
| `#/` | 首頁 | 主視覺、選擇出發梯次、團體安排、行程特色、店家數、五天行程一覽、簽名支持 |
| `#/itinerary` | 每日行程 | 梯次切換、Day 01–05 展開列（`#/itinerary/3` 會直接打開 Day 3） |
| `#/price` | 出團日期與價格 | 兩個梯次、每人費用明細（廉航／傳統航空）、費用包含與不包含 |
| `#/stay` | 住宿交通 | 飯店、機場接送／地鐵／計程車、計程車車資表 |
| `#/spots` | 店家一覽 | 36 家店，依分類、天數、關鍵字篩選 |
| `#/notes` | 參團說明 | 氣候與穿搭、行程小提醒、出發前準備、費用與資料說明 |

頁面名稱和每頁上方的說明文字在 `tour.js` 的 `PAGES`。

## 配色

版型參考吉光旅遊商品頁，配色是莫蘭迪灰藍：主色霧灰藍 `#8fa3b3`（按鈕用深一點的 `#5f7686`，白字才看得清楚）、點綴色奶茶 `#b09a86`（Day 01 這類標籤）、捲動後出現的行程列是石板灰 `#5c6770`。品牌組員定案後改 `style.css` 最上面的 `--main`、`--accent` 變數即可。

## 怎麼打開

直接用瀏覽器打開 `index.html` 就可以看，不用安裝任何東西。字體從 Google Fonts 載入，所以要有網路。

## 放照片和 logo

1. 把照片放進 `images/` 資料夾。
2. 打開 `js/tour.js`，在 `PHOTOS` 裡把對應的 `src: ''` 改成檔名，例如 `src: 'images/hero.jpg'`。
3. 每個照片位置都有 `hint`（建議放什麼）和 `file`（建議檔名），沒放照片的位置會顯示灰色提示框。

logo 和旅行社名稱在 `tour.js` 最上面的 `BRAND`：`agencyName`、`logo`、`slogan`、`groupLabel`。

照片請用可以免費使用的圖庫，例如 [Unsplash](https://unsplash.com/s/photos/osaka)、[Pexels](https://www.pexels.com/search/osaka/)，或組員自己拍的照片。Pinterest 上的圖大多是別人的作品轉貼，沒有授權，不建議直接拿來用。

## 售價

`tour.js` 裡的 `TOUR.sellingPriceTwd` 目前是 `null`，網頁會顯示用預算算出來的金額（廉航方案 ¥126,500 ÷ 4.8 = NT$26,354）。組內決定售價後填數字即可，例如 `26900`。

## 跟原版相比

### 保留（底層邏輯）

- `data.js` 的資料一個字都沒改：`seasonConfig`、`itineraryData`、`directoryItems`、`budgetDatasets`、`taxiRoutes`。
- 冬日團／夏日團切換：切換後，每日行程的日期、提醒文字、穿搭建議都會跟著換。
- 每日行程 Day 1–5：時段、店名、營業時間、地址、費用、Google 地圖連結、備案都在。
- 預算方案切換：廉航超值方案（¥126,500）／傳統航空方案（¥180,000）。
- 店家目錄：依分類、天數、關鍵字篩選。
- 住宿、機場大巴、地鐵、計程車費率的說明文字，以及出發前檢查清單。

### 更動（只改呈現方式）

| 原版 | 新版 | 原因 |
| --- | --- | --- |
| 先進「選團首頁」，再進儀表板 | 「出團日期與價格」列出兩個梯次，點一下就切換 | 旅行社商品頁的寫法，一個行程、兩個梯次 |
| 一整頁塞滿所有資訊 | 拆成 6 頁（首頁、每日行程、出團日期與價格、住宿交通、店家一覽、參團說明） | 一頁資訊太多 |
| Day 1–5 分頁按鈕 | 可展開的 Day 01–05 列，每天有上午／下午／晚上／住宿一覽和兩張照片位置 | 參考吉光商品頁 |
| 預算圓餅圖（Chart.js） | 費用明細表＋比例條 | 金額比較好讀，也不用載入圖表套件 |
| 計程車下拉選單試算 | 五個路段一次列成表格 | 不用一個一個點 |
| 氣溫與降雨圖表（含東京對照） | 拿掉圖表，只留歷年平均文字和穿搭建議 | 東京資料跟這個行程無關，圖表也容易被誤會成天氣預報 |
| 檢查清單彈出視窗 | 「參團說明」頁的「出發前準備」三步驟 | 不用多點一次 |
| 首頁寫「16:30 準時回飯店」 | 改成「傍晚先回飯店放戰利品」 | Day 2–4 的資料寫的是 17:30／18:15，兩邊對不起來 |
| Tailwind、Chart.js、Font Awesome 三個外部套件 | 全部拿掉，自己寫 CSS | 載入比較快，外觀也不會被套件綁住 |
